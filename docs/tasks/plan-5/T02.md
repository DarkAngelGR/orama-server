## Report

- **Agent `self-update` (`src/orama_agent/runner.py`, `src/orama_agent/server.py`, `src/orama/agent_client.py`)**:
  - Added `"self-update"` to `COMMANDS` in `src/orama_agent/server.py`.
  - `Agent.self_update(args)` enforces `_expect_keys(args, set())` (refusing any arguments), verifies `<config_root>/core.compose.yaml` is a regular file through no-follow directory file descriptors (`_DIR_FLAGS` + `_read_regular`), ensures `<config_root>/app-env/compose.env` (`0600`) exists, and invokes `runner.self_update()`.
  - `ComposeRunner.self_update()` pulls core images under `PULL_TIMEOUT` (3600s), removes any lingering `orama-updater` container, and launches an independent helper container (`orama-updater`) mounting `/var/run/docker.sock` and `<config_root>`. The helper container executes `docker compose --project-directory <config_root> --env-file <app-env/compose.env> -p orama-core -f <config_root>/core.compose.yaml up -d --remove-orphans --wait`, preventing the Agent from terminating its own client execution mid-command. If `pull` fails, `RunnerError` is raised before launching the helper container, leaving running containers untouched.
  - Added `AgentClient.self_update() -> bool`.
- **Web UI trigger (`src/orama/web/settings.py`, `src/orama/web/templates/settings/index.html`)**:
  - Added `POST /settings/update-orama` protected by `@auth.requires("settings")` and CSRF, guarded against missing setup (`409`), unfinished `setup.draft.json` (`409`), and concurrent apply/test jobs (`apply_operation(st)` + non-blocking `apply.lock` -> `409 TEST_BUSY`).
  - Added the "Update Orama" section in Settings (`settings/index.html`). The same change was also made to the
    Node demo server (`server.ts`, `views/settings/index.ejs`); those files were removed from the repository on
    2026-11-11 (review finding F1) and are no longer part of this task.
- **Tests (`tests/agent/test_server.py`, `tests/web/test_settings.py`, `tests/integration/test_install_and_apply.py`)**:
  - Added unit tests for `self-update` missing core compose refusal, argument refusal, symlink refusal, `ComposeRunner.self_update` argv/timeouts and pull-failure safety, and `POST /settings/update-orama` success, `502` error propagation, `409` draft block, and `409` busy apply block.
