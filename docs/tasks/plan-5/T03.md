## Security Audit Report

- **Zero-Secret Guarantee**: Audited all templates, static scripts, and HTTP responses. No passwords, private tokens, or sensitive network credentials appear in HTML payloads, URLs, or exception output.
- **CSRF & Session Validation**: State-modifying requests (POST/PUT/DELETE) enforce CSRF verification.
- **IFrame Cookie Isolation**: Configured cookies with `SameSite=None; Secure` with robust session storage fallback to prevent login loops in embedded browser environments.
- **Host Header Allowlisting**: Verified host validation against configured server names and LAN addresses.
