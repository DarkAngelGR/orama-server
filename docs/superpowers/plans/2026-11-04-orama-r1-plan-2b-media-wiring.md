# Release 1 Plan 2b — Subtitles, quality and media servers

> Use superpowers:executing-plans or superpowers:subagent-driven-development to execute one unchecked task at a time.

**Goal.** After apply, the selected media servers have Movies and TV libraries, new imports trigger a refresh, and the download apps favor releases and subtitles suited to the selected playback device.

**Architecture.** Extend DesiredSetup, SecretStore and the existing ordered Step engine. Orama drives the app APIs on orama-net. The Agent performs only narrowly specified filesystem and container operations. Use the pinned images in src/orama/catalog.py and the existing Python, pydantic, pytest and Docker tooling.

**Spec.** Read [Release 1 design](../specs/2026-11-03-orama-release-1-design.md), especially §§4–6 and 10, and [carry-forward notes](2026-11-03-orama-r1-plan-1-notes.md). Baseline fc4e513. Owner deferred the separate Plan 2a scan and authorized moving forward. The first unchecked task is the resume point.

## Global constraints and review focus

Follow AGENTS.md for each task. Claim it in STATUS, run the failing test before implementing, run the fast checks, sign and push to main, inspect all four CI jobs, then record the commit, result and next task. At handoff, distinguish observed behavior from assumptions awaiting a pinned-image test.

Use service names and container ports internally. Media roots are /data/media/movies and /data/media/tv. Preserve user entries and unrelated fields. Second apply must produce no configuration writes, duplicate libraries, repeated claims or unnecessary restarts. Retry independent services after partial success. Use generated fake credentials in CI.

Only the network-isolated Agent has the Docker socket. Keep app secrets out of setup.json, compose, arguments, logs, URLs captured by logging, exceptions and test artifacts. Any new builder output must have matching exact Agent pins and refusal tests. App-owned files are hostile. Use fixed paths, bounded reads, no-follow directory descriptors and atomic replacement. No general file writer, shell or Docker command interface.

## Tasks

- [ ] **1. Establish pinned-image contracts.** Start in tests/integration/ and src/orama/catalog.py. On a disposable Linux Docker host verify how the pinned Bazarr reads its key and reloads settings, how the Recyclarr image accepts config and runs once, which Jellyfin startup steps remain available after completion, and which notification types each pinned arr exposes. Record sanitized request/response shapes, readiness checks, writable fields, and failure codes in a companion Plan 2b notes file. For Plex separate locally testable server operations from owner-only account approval and Plex Pass checks. Never check in a real response with a token. Stop any adapter whose contract cannot be verified and record exactly what experiment remains.
- [ ] **2. Persist playback preferences.** Extend src/orama/setup_model.py and tests/test_setup_model.py. Add ordered subtitle languages (suggest Greek then English), device choice (Samsung S95F, LG, Apple TV, Shield, safest) and quality choice (4K, 1080p, mixed). Load existing setups with mixed movie/TV quality and conservative device defaults. Round-trip ordering, reject unknown choices and duplicate languages, and prove account secrets never enter serialized setup. Keep first-run credentials in the existing encrypted store through restricted secret names and stdin input.
- [ ] **3. Configure Bazarr.** Extend src/orama_agent/seed.py and its dispatch/client only as Task 1 requires. Test malformed keys, symlinks, unexpected paths, oversized config and unchanged settings before adding the fixed seed format. Add src/orama/wiring/bazarr.py and tests/wiring/test_bazarr.py. Wait for readiness, connect only enabled Sonarr/Radarr instances using their stored keys, and reconcile an Orama-owned language profile, free providers and SRT preference. Allow optional provider credentials only through SecretStore. Verify fallback language availability leaves the first language wanted. Test partial startup and a second run with zero writes.
- [ ] **4. Compile quality and device profiles.** Add package data under src/orama/profiles/ and a profile compiler with tests/test_profiles.py. Map mixed quality to movie 4K and TV 1080p. Layer device scores on the TRaSH base. For S95F test HDR10/HDR10+ preference, DV profile 5 without fallback, DTS, multichannel LPCM/FLAC and TrueHD per spec §6.1. Keep unverified devices best-effort. Test deterministic output, score precedence, preservation of non-Orama formats and switching devices without leaving obsolete Orama scores. Distinguish release-name predictions from observed playback.
- [ ] **5. Apply Recyclarr on demand.** Implement src/orama/wiring/recyclarr.py with a fixed, validated one-shot Agent operation if the pinned image requires it. Generate config from validated choices, inject only the required arr credentials, and pin command, image, network, mounts and inputs on both sides. Do not accept caller YAML or arbitrary commands. Verify the resulting profiles and scores through each enabled arr API. Record success only after verification. Test unchanged state, drift, failed sync followed by retry, user-owned formats, removed apps, and absence of credentials from process arguments and output.
- [ ] **6. Implement Plex sign-in and setup.** Add src/orama/wiring/plex.py and tests/wiring/test_plex.py. Expose begin and poll operations reusable by the future wizard. Validate a fixed HTTPS Plex origin, expiry and a stable client identifier. Return only the user approval URL/code to the caller. Keep the resulting token server-side. Check server identity and claim state before claiming, and refuse to take over a server belonging to another account. Find libraries by media type and path before creating them. Set hardware preferences only for supported detected hardware and entitlement. Test pending, denied, expired, already claimed, missing Pass, and retry after just one library was created. Test external HTTP through a fake Plex service and reserve live account approval for the owner.
- [ ] **7. Implement Jellyfin first run.** Add src/orama/wiring/jellyfin.py and tests/wiring/test_jellyfin.py. Discover startup state, create the requested admin from stored credentials, complete startup, authenticate and reconcile both libraries. Never reset an existing admin to recover from a retry. Cover a failure between admin creation and wizard completion, an already configured server with invalid credentials, custom libraries and no GPU. Select QuickSync or NVENC only for detected capability. Verify bridge networking with the published host port. If NVIDIA requires an extra env setting, pin its exact value in compose.py and orama_agent/validate.py with positive and negative tests.
- [ ] **8. Connect import refresh and apply order.** Extend src/orama/wiring/arr.py, wiring/plan.py and cli.py. Create named Orama refresh connections only for enabled Sonarr/Radarr and media-server pairs once authentication and libraries are ready. Remove only Orama connections when a server is deselected. Preserve existing Plan 2a wiring. Test Plex only, Jellyfin only, both, and pending Plex approval while independent Jellyfin and subtitle steps succeed. A failed step names the app and the corrective action without exposing credentials.
- [ ] **9. Prove installation and retry.** Extend tests/integration/test_install_and_apply.py using the pinned images. Inspect actual API state after first and second apply. Assert subtitle links and language order, profile assignments/scores, libraries and refresh targets, stable container IDs where no restart is required, and no leaked secrets. Simulate interruption and verify a subsequent apply changes only unfinished work. Record owner checks for actual Plex claim/Pass, LAN discovery, hardware acceleration and Samsung direct play. Record passed, failed and untested items separately before marking the milestone complete.
